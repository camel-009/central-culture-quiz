🚀 วิธีนำไฟล์ไปสร้างเป็นเว็บแชร์ออนไลน์

เพื่อให้คนอื่นสามารถกดลิงก์จากมือถือเข้ามาทำแบบทดสอบและส่งคะแนนรวมกันได้ ให้เลือกนำไฟล์ index.html ไปอัปโหลดผ่านเว็บโฮสติ้งฟรีได้ 3 วิธีง่ายๆ ดังนี้ครับ:

1. Netlify Drop (แนะนำ - เร็วที่สุด)

สร้างโฟลเดอร์ นำไฟล์ index.html ใส่ไว้ข้างใน แล้วลากโฟลเดอร์ไปวางที่ app.netlify.com/drop จะได้ลิงก์เว็บ https:// ทันที

2. Tiiny.host (อัปไฟล์เดี่ยวได้เลย)

เข้าเว็บ tiiny.host แล้วลากไฟล์ index.html วางในช่องอัปโหลด ตั้งชื่อลิงก์แล้วกด Launch

3. GitHub Pages (เปิดฟรีถาวร)

อัปโหลดไฟล์ index.html เข้าไปใน GitHub Repository แล้วเปิดใช้งาน Pages ในเมนู Settings
